Aurora Steam Client / Linux & Proton

Linux gaming · Wayland & X11 · No Chromium

A native Steam client for Linux without steamwebhelper

Aurora brings a single-process Rust desktop client to Wayland and X11—launching native Linux builds, Windows games through Proton, SteamStub DRM titles, and anti-cheat games while keeping your system lean.

Install on Arch, Debian, Fedora See 166 MB vs 1.4 GB benchmarks

How every type of Steam game launches on Linux

Aurora inspects each game and picks the right launch path automatically. Games with both a Linux and Windows build run natively by default, and Manage › Compatibility lets you switch any game to a specific Proton version.

Game type Launch path Steam APIs & DRM
Native Linux games Launched directly Uses your installed Steam's steamclient.so through Aurora's windowless Steam host (no Chromium UI).
Windows games (Proton) Proton (Steam's default, or your per-game choice) Aurora's Rust steamclient handles achievements, stats, Steam Cloud, lobbies, Workshop, and P2P.
Steam DRM (SteamStub) Proton + windowless Steam host Valve's own engine answers the DRM and ownership check fail-closed—no bypasses or cracks.
Anti-cheat (VAC, EAC, BattlEye) Official Steam client by default Handed off to Valve's official client so anti-cheat runs in a fully supported environment.

Built for modern Linux desktops

Wayland, X11 & Hide-to-Tray

Aurora runs natively on Wayland and X11 without requiring GTK. Hiding to the system tray unmaps the window and trims cached textures and heap memory so Aurora stays almost invisible in the background.

Linux Vulkan Shift+Tab Overlay

Aurora includes a Vulkan implicit layer for native Vulkan and fullscreen DXVK/VKD3D Proton games—giving you Shift+Tab friends, chat, achievements, persistent per-game notes, F12 screenshots, and an FPS counter HUD.

Per-Game Proton & Shader Cache

Pick any installed Proton or Proton-GE version per game in Manage › Compatibility. Aurora uses Steam's shader cache and pre-compiles Fossilize shaders before launch to reduce in-game stutter.

Declarative Themes & Native Adwaita

Ship with built-in presets including NEVKO, Native Adwaita (for GNOME desktops), Steam Desktop Replica, OLED, and Daylight—or install custom .aurora-theme packages.

Linux requirements

  • Steam installed on disk: Aurora reuses your existing Proton installations and Valve's engine for the windowless Steam host (and launches anti-cheat titles through the official client).
  • Store trailers & Steam Broadcasts: Install ffmpeg and libpulse (PulseAudio or PipeWire's Pulse compatibility layer) for hardware-friendly video and audio playback.
  • Packages available: Native packages for Arch Linux (.pkg.tar.zst), Debian/Ubuntu/Mint (.deb), Fedora (.rpm), and a portable .tar.gz tarball. See the Install Guide.
