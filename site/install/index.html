Aurora Steam Client / Install

Downloads · Linux x86_64 & Windows 10/11

Download & install Aurora Steam Client

Every release ships native Linux packages for Arch, Debian/Ubuntu, and Fedora, a universal Linux tarball, and both an auto-updating installer and portable archive for Windows 10 & 11—with SHA256SUMS.txt verification.

Linux installation

Download the package for your distribution from the latest GitHub release. Keep Steam installed on disk for Proton and the windowless Steam host; install ffmpeg and libpulse for trailers and Steam Broadcasts.

Arch Linux / CachyOS / Manjaro

Download aurora-bin-<version>-x86_64.pkg.tar.zst and install with pacman:

$ sudo pacman -U ./aurora-bin-*-x86_64.pkg.tar.zst

Debian, Ubuntu 22.04+, Linux Mint, Pop!_OS

Download aurora_<version>_amd64.deb and install with apt:

$ sudo apt install ./aurora_*_amd64.deb

Fedora / Nobara / RHEL-family

Download aurora-<version>.x86_64.rpm and install with dnf:

$ sudo dnf install ./aurora-*.x86_64.rpm

Generic Linux tarball

Download Aurora-Linux-x86_64.tar.gz, extract anywhere, and run:

$ tar -xzf Aurora-Linux-x86_64.tar.gz
$ ./aurora

Windows 10 & 11 installation

Windows Installer (recommended)

Download Aurora-Setup-<version>.exe from the latest release. It installs per-user without administrator rights, creates Start Menu shortcuts, and automatically checks for updates (including SemVer prereleases).

If Windows SmartScreen warns about an unsigned open-source binary, choose More info → Run anyway.

Windows Portable ZIP

Download Aurora-<version>-portable.zip, extract to any folder, and run aurora.exe. No installer or registry entries required.

Build from source (Rust)

Requires Rust. To preview Aurora without signing in, pass --demo. For Proton games on Linux, copy the CI-built Windows steamclient DLLs from a release next to your compiled binary.

$ git clone https://github.com/mollie2999/Aurora.git
$ cd Aurora
$ cargo build --release -p aurora -p steamhost
$ target/release/aurora          # sign in with your Steam account
$ target/release/aurora --demo   # sample library, no sign-in

Verify downloads (SHA-256)

Every GitHub release includes SHA256SUMS.txt so you can verify your package before installing:

$ sha256sum -c --ignore-missing SHA256SUMS.txt
