# Metro

An Aurora port of [MetroSteam](https://github.com/RoseTheFlower/MetroSteam) by RoseTheFlower,
itself inspired by the original Metro for Steam skin.

- One flat 38px title bar: collapsed root menu, back/forward, uppercase supernav,
  friends / downloads / notifications icons, uppercase account with a square avatar,
  and Windows 10 window controls. There is no bottom bar.
- Pure black client (`--clientBG`, `--header_dark`, `--bgGameList` = black), square corners,
  white overlays (`white05`, `white12`, `white24`) for hover and button surfaces.
- Game list rows fill with the solid accent when selected, as in Metro.
- Options: **Variation** (Standard, Dark, Midnight, White) and **Accent Color**
  (all of MetroSteam's presets).

Not ported: the remote decal images and the free-form custom accent picker. Use an
Accent Color preset instead.

## Font

Selawik (`assets/fonts`) is Microsoft's open-source, metric-compatible replacement for
Segoe UI, licensed under the SIL Open Font License 1.1 (see `assets/fonts/OFL.txt`).
Segoe UI itself is not redistributable.
