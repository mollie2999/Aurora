Frequently asked questions

Safety, anti-cheat & how Aurora works

Straight answers about Steam account security, VAC/EAC/BattlEye handling, how Aurora compares to SteamInRust, and what Aurora Steam Client is (and isn't).

Is Aurora Steam Client safe to use with my Steam account?

Aurora signs in using the same Steam authentication protocol as the official desktop client and Steam Mobile app (password, Steam Guard, or QR code). Your credentials stay on your machine in private user storage and are only sent directly to Steam. The entire codebase is MIT-licensed on GitHub with zero telemetry—outside of Steam, Aurora only contacts GitHub for updates, an exchange-rate API when checking gift regions, and optionally IsThereAnyDeal if you add your own API key.

Can Aurora get me banned in VAC, Easy Anti-Cheat, or BattlEye games?

By default, no: Aurora never injects into or modifies anti-cheat games. Any game using VAC, Easy Anti-Cheat, or BattlEye automatically launches through Valve's official Steam client so its anti-cheat runs in a normal supported environment.

On Linux, there is an opt-in experimental toggle in Settings › Library to run anti-cheat titles via the windowless Steam host; it is off by default and carries a warning because anti-cheat vendors may treat non-standard hosts as unsupported.

How is Aurora Steam Client different from SteamInRust?

Aurora began as a fork of SteamInRust by madonchik123 and expanded it into a cross-platform Linux + Windows client. Aurora adds native Wayland and X11 support, Proton launching with per-game compatibility selection and shader cache pre-compilation, a windowless Steam host for native Linux and SteamStub DRM games, a Linux Vulkan Shift+Tab overlay, Wayland/X11 hide-to-tray, native Arch/Debian/Fedora packages, a declarative custom theme engine (including Native Adwaita and Steam Desktop Replica), live Steam Broadcasts, Steam Input controller calibration, and extensive security hardening.

Is Aurora Steam Client related to Aurora Linux, Cheat Happens Aurora, or Daturaxoxo/Aurora?

No. Several unrelated projects share the word "Aurora":

  • Aurora Steam Client (this project, mollie2999/Aurora): an open-source Rust desktop client for Steam on Linux and Windows.
  • Aurora Linux (Universal Blue): a Linux desktop operating system image.
  • Cheat Happens Aurora: a commercial PC game trainer utility.
  • Daturaxoxo/Aurora: an Unreal Engine mod manager and launcher.

Do I still need official Steam installed on Linux?

Yes, you keep Steam installed on disk so Aurora can reuse Proton, Steam's shader cache, and Valve's engine for the windowless Steam host (and hand off anti-cheat games). You don't need to launch or leave the heavy Chromium Steam desktop interface running.

Does Aurora bypass Steam DRM or let people run unowned games?

No. Aurora's ownership and DRM handling is strictly fail-closed. SteamStub DRM and native Linux games authenticate through Valve's own engine on the windowless Steam host, which verifies that your signed-in account owns the game.

What features are still missing?

Big Picture mode, Remote Play, and voice chat are not implemented yet. Store checkout opens Steam's official website as Valve requires. Everything else—store, search, Discovery Queue, Points Shop, library, downloads, friends, chat, community, live broadcasts, Workshop, inventory, Market, trading, Cloud saves, Shift+Tab overlay, themes, and plugins—works natively.
