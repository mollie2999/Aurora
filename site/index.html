The windowless Steam host is your installed Steam's engine without its interface: no steamwebhelper, no Chromium. It checks ownership itself, so it can't start a game you don't own. Running anti-cheat games on it (Settings › Library) is experimental: the anti-cheat may count it as an unsupported setup and ban you. Read the full Linux & Proton guide · Anti-cheat FAQ

Build from source

Needs Rust. The Windows steamclient DLLs that Proton games load are built by CI; copy them next to the binary from a release. --demo opens the client with sample data, without signing in.

$ git clone https://github.com/mollie2999/Aurora.git
$ cd Aurora
$ cargo build --release -p aurora -p steamhost
$ target/release/aurora          # sign in with your account
$ target/release/aurora --demo   # sample data, no sign-in

Your sign-in

Aurora signs in the way the official client and the Steam Mobile app do. Your sign-in stays on your PC and is only sent to Steam.

Anti-cheat

By default, anti-cheat games always run through Valve's own client. The windowless host for them is opt-in and marked experimental.

No telemetry

Aurora connects to Steam, GitHub for updates, an exchange-rate service for gift regions and, if you add a key, IsThereAnyDeal.
